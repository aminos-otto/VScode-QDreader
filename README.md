# 起点阅读：VS Code 侧边栏扩展（非官方）

在 VS Code 侧边栏浏览起点作品，并阅读当前 Edge 登录账号**已经有权访问**的章节。本项目由个人开发，与起点中文网及其关联公司无关；没有使用起点官方开放 API，也不提供购买、解密、离线书库或绕过网站验证的功能。

项目包含两部分：VS Code 扩展和 `edge-companion` Edge 辅助扩展。辅助扩展从你正常打开的起点官方网页读取已显示的内容，经本机 `127.0.0.1:17843` 传给 VS Code。**仓库不包含小说正文、账号凭证或配对码。**

## 功能

- 发现、书架、搜索、作品目录和最近 50 条阅读历史。
- 目录与正文在侧边栏同一位置切换；可选在编辑区阅读。字号、主题、章节切换和阅读位置恢复可用。
- 点击正文的段评标记，在下方独立视图查看只读段评，同时保留对应段落可见。段评只显示昵称与评论内容；网页结构无法识别时显示不可用。
- 免费章节及账号在官方网页上能够完整显示的已购 VIP 章节可在插件内阅读。未购或未能确认正文完整的章节保持锁定。

## 环境与安装

- VS Code 1.85 或更新版本、Microsoft Edge。
- 如从源码打包：Node.js 20 或更新版本、npm。

1. 获取本仓库，在项目根目录运行：

   ```powershell
   npm ci
   npm run package
   ```

2. 在 VS Code 命令面板运行 **Extensions: Install from VSIX...**（扩展：从 VSIX 安装），选择生成的 `qidian-reader-personal-*.vsix`。
3. 在 Edge 打开 `edge://extensions`，启用开发人员模式，点击“加载解压缩的扩展”，选择本仓库的 `edge-companion` 文件夹。更新该文件夹后，在此页面点击辅助扩展的“重新加载”。

## 首次连接与阅读

1. 在平时使用的 Edge 中，正常登录起点并打开起点首页。登录与购买都只在起点官方网页进行。
2. 在 VS Code 命令面板运行 **起点阅读: 连接普通 Edge 并复制配对码**。
3. 点击 Edge 工具栏中的“起点阅读 · VS Code 页面传送”，粘贴配对码，点击“发送当前页面”。保持“自动同步”开启，后续正常显示的起点页面会自动传送。
4. 在 VS Code 活动栏打开“起点阅读”。选择作品、章节，或使用搜索、书架与阅读历史。点击章节后，辅助扩展会在 Edge 后台标签页打开官方页面；待官方网页正常显示，正文才会传到 VS Code。

连接失败时，检查 VS Code 扩展是否已启动、Edge 辅助扩展是否已加载，以及本机端口 `17843` 是否被占用。章节显示锁定时，先确认同一账号在普通 Edge 的起点官网能否完整阅读；插件不会处理验证码或订阅。网站改版可能使作品列表、正文或段评提取失效。

## 隐私与数据流

| 数据 | 处理方式 |
| --- | --- |
| 起点登录状态 | 保留在普通 Edge。当前辅助扩展不读取 Edge Cookie 或密码。 |
| 配对码 | VS Code `SecretStorage` 与 Edge 扩展本地存储各保存一份；连接时会复制到系统剪贴板。不要将它粘贴到 Issue、截图或仓库。 |
| 章节正文与段评 | 从已显示的官方网页传到本机回环地址，仅供当前阅读；不写入本仓库或离线书库。 |
| 阅读历史与位置 | VS Code 本地 `globalState` 保存章节标题、链接、时间与滚动位置，不保存正文。 |

“断开 Edge 并清除阅读记录”会清除插件保存的配对码、历史和位置，但**不会退出 Edge 中的起点账号**。代码中保留部分旧版会话兼容逻辑；如果本机旧版本曾保存会话 Cookie，它们位于 VS Code `SecretStorage`，不在项目目录中，也会随上述清除操作删除。
